# منصة المهام الذكية والعمولات الترويجية | IQ VIP Task Platform

منصة متكاملة لإدارة المهام الترويجية وعمولات المنتجات باللغة العربية مع دعم كامل للاتجاه من اليمين إلى اليسار (**Arabic RTL**)، ومظهر بصري ملكي يعتمد درجات الذهبي الفاخر والأبيض والأزرق الداكني الملوكي (**Dark Navy & Gold Theme**)، مبنية بنظام محاسبي مزدوج القيد وسجل مالي غير قابل للتعديل (**Immutable Financial Ledger**).

---

## 🌟 الميزات الرئيسية (Key Highlights)

### 1. واجهة المستخدم وتجربة الاستخدام (UI & UX)
- **لغة عربية أصيلة وتصميم RTL أصيل**: خطوط عربية فاخرة (Cairo & Tajawal) مع محاذاة يمنى وتنسيق سلس لجميع العناصر.
- **ثيم بصري VIP حديث**: تدرجات اللون الذهبي الملكي (`#D4AF37`)، الأزرق الكحلي الليلي (`#070D1E`)، والأسطح الزجاجية المعتمة (**Glassmorphism**).
- **تصميم متجاوب متوافق مع الهواتف المحمولة أولاً (Mobile-First)**: تجربة مستخدم سلسة على شاشات الهواتف الذكية مع شريط تنقل سفلي بخمسة أقسام رئيسية:
  1. **الرئيسية (Home)**: بطاقة الرصيد التفاعلية، إحصائيات المهام اليومية، ونسبة الإنجاز.
  2. **المهام (Tasks)**: استعراض المنتجات المتاحة عشوائياً، مؤقت المعالجة التفاعلي (30 ثانية)، وتقييم المنتج.
  3. **VIP (Membership)**: استعراض مستويات العضوية (VIP1 إلى VIP4) والشروط والفوائد بشفافية.
  4. **المحفظة (Wallet)**: تفصيل الأرصدة (المتاح، المعلق، المكتسب، والمسحوب)، ونموذج طلب السحب، وسجل القيود المحاسبية.
  5. **حسابي (Profile)**: بيانات الحساب، التوثيق، كود الإحالة، وتبديل النمط التجريبي.
- **مؤثرات صوتية اصطناعية (Web Audio API Synthesizer)**: رنين بدء المهمة، نبضات المؤقت التنازلي، ونغمة احتفالية عند إيداع العمولات بنجاح دون الحاجة لملفات صوتية خارجية.

### 2. نظام المهام ومؤقت المعالجة (Task Engine & 30s Timer)
- **اختيار عشوائي ذكي**: اختيار منتج مؤهل من قاعدة البيانات يتناسب مع مستوى VIP الخاص بالمستخدم.
- **معالجة زمنية مراقبة من الخادم (Server-side 30-Second Processing Period)**:
  - مؤقت دائري تفاعلي مع شريط تقدم ثلاثي المراحل:
    1. مطابقة بيانات المنتج مع منصات التجارة المعتمدة.
    2. تأكيد تقييم المستهلك ومراجعة الجودة.
    3. تسوية العمولة في المحفظة المالية.
  - يرفض الخادم بشكل صارم أي محاولة لإنهاء المهمة قبل انقضاء الـ 30 ثانية لمنع التحايل والبوتات.
- **منع تكرار المهام وصرف العمولات المزدوج (Anti-Replay & Idempotency)**:
  - قيود فريدة على مستوى قاعدة البيانات (`UNIQUE constraint on task_id`).
  - معالجة ذرية داخل معاملة قاعدة البيانات (`ACID Transaction`).

### 3. المحفظة والسجل المالي المحصن وشروط السحب الإلزامية (Financial Ledger & Withdrawal Rules)
- **الشرط الأول والأساسي للسحب (Mandatory Daily Tasks Completion)**:
  - لا يمكن للمستخدم تقديم طلب سحب مالي إلا بعد **إكمال جميع المهام اليومية** المخصصة لمستوى عضويته (VIP1: 5 مهام، VIP2: 12 مهمة، إلخ).
  - يتم فحص هذا الشرط بشكل صارم على الخادم (`Server-Side Guard`) ويرفض الخادم أي طلب سحب إذا لم تكتمل المهام اليومية بالكامل.
- **كل شيء حقيقي - إلغاء الأرصدة الافتراضية (No Virtual Credits)**:
  - يبدأ المستخدمون الجدد برصيد حقيقي **0.00** فقط، ويتم تحقيق الأرباح حصراً من خلال تنفيذ المهام أو الشحن الفعلي.
  - تم إخفاء وعزل لوحة المشرف وعدم فضح روابطها أو بيانات الدخول الافتراضية في واجهة المستخدم العامة.
- **إدارة طرق الدفع والسحب من لوحة التحكم (Payment Methods CRUD)**:
  - يستطيع المشرف من لوحة التحكم إضافة وسائل دفع جديدة (مثل Zain Cash، USDT TRC-20، Qi Card، الحوالات المصرفية، المحافظ المحلية)، وتعديل الرسوم، والحدود الدنيا والقصوى، وتفعيلها أو تعطيلها بنقرة واحدة.
  - تظهر وسائل الدفع النشطة تلقائياً في قائمة السحب لدى المستخدمين.
- **تخصيص اسم وعملة الموقع من الإعدادات (Custom Platform Currency)**:
  - يستطيع المشرف تغيير رمز واسم العملة المعتمدة للمنصة من لوحة التحكم (مثل: `USDT`، `د.ع`، `IQD`، `$`)، وتنعكس مباشرة على جميع الشاشات والمحافظ والبطاقات.
- **سجل المعاملات والقيود المحاسبية الشامل (Transactions History)**:
  - نافذة تفاعلية كاملة لسجل المعاملات مع تصفية متقدمة حسب نوع المعاملة (الكل، عمولات المهام، طلبات السحب، السحوبات المعتمدة، التسويات).

### 4. مستويات عضوية VIP (VIP1 - VIP4)
- **VIP1 البرونزي**: 5 مهام يومياً | عمولة 0.6% | رسوم سحب 2.5%.
- **VIP2 الفضي**: 12 مهمة يومياً | عمولة 1.2% | رسوم سحب 2.0%.
- **VIP3 الذهبي**: 25 مهمة يومياً | عمولة 2.0% | رسوم سحب 1.5%.
- **VIP4 البلاتيني**: 40 مهمة يومياً | عمولة 3.5% | رسوم سحب 1.0%.
- **إخلاء مسؤولية صريح وشفاف**: المنصة لا تقدم أي وعود بعوائد مالية مضمونة أو استثمارات ثابتة؛ العمولات ترويجية مرتبطة بإنجاز المهام فقط.

### 5. لوحة الإدارة والرقابة الشاملة (Admin Portal & Audit Trail)
- متوفرة عبر الرابط: `http://localhost:3000/admin`
- **المؤشرات الحيوية والمالية (KPIs)**: إجمالي المستخدمين، العمولات المدفوعة، الالتزامات المعلقة، وتوزيع مستويات VIP.
- **إدارة طلبات السحب**: اعتماد فوري مع تسوية السجل المالي، أو رفض مع تسجيل سبب معتمد وإعادة الرصيد تلقائياً.
- **إدارة المستخدمين والحسابات**: بحث وتصفية، تجميد أو تنشيط، تعديل مستويات VIP، وتعديل الأرصدة يدوياً مع قيد تدقيق إداري.
- **كتالوج المنتجات**: إضافة منتجات عربية فاخرة، تعديل الأسعار، وتحديد مستوى VIP الأدنى.
- **تكوين إعدادات النظام**: تعديل مدة معالجة المهمة (30 ثانية افتراضياً)، الحد الأدنى للسحب، ونسب الرسوم.
- **سجل التدقيق الإداري (Audit Trail)**: توثيق دائم لكل حركة إدارية مع عنوان IP والمشرف والطابع الزمني.

## 🗄️ النشر على خادم إنتاج مع قاعدة بيانات PostgreSQL

الملف `database/schema.postgres.sql` يحتوي على المخطط الإنتاجي الكامل لـ PostgreSQL.

### خطوات النشر مع PostgreSQL:
1. أنشئ قاعدة البيانات في PostgreSQL:
   ```sql
   CREATE DATABASE iq_vip_db;
   ```
2. استورد الجداول والمخطط:
   ```bash
   psql -U postgres -d iq_vip_db -f database/schema.postgres.sql
   psql -U postgres -d iq_vip_db -f database/seed.postgres.sql
   ```
3. قم بضبط متغير البيئة `DATABASE_URL` في ملف `.env`:
   ```env
   DATABASE_URL=postgresql://user:password@localhost:5432/iq_vip_db
   PORT=3000
   ```
4. شغّل الخادم:
   ```bash
   npm start
   ```

## 🔌 بوابات الدفع الخارجية (External Payment Providers)

تم تصميم النظام ليكون مستقلاً ويعمل بكفاءة دون الحاجة لربط فوري، مع توفير خطافات برمجية جاهزة للربط مع بوابات الدفع الحقيقية عند الانتقال للإنتاج:
1. **USDT Tron TRC-20**:
   - الخطاف: `TRON_GRID_API_KEY` في ملف `.env`.
   - يستخدم لمراقبة الإيداعات الآلية على شبكة Tron وتنفيذ السحوبات آلياً عبر العقود الذكية لـ USDT.
2. **محفظة زين كاش (Zain Cash - العراق)**:
   - الخطاف: `ZAIN_CASH_MERCHANT_ID` و `ZAIN_CASH_SECRET`.
   - لدعم الشحن والسحب بالدينار العراقي للمستخدمين المحليين.
3. **مصرف الرافدين / كي كارد (Qi Card)**:
   - الخطاف: `QI_CARD_API_KEY`.
   - لمعالجة التحويلات المصرفية المحلية المباشرة.

## 🛡️ إرشادات الأمان والنزاهة المالية (Security Standards)

1. **التحقق المركزي من الخادم**: لا يتم الوثوق إطلاقاً بأي مبالغ عمولة أو أرصدة مرسلة من جانب العميل؛ يقوم الخادم باحتساب العمولة بناءً على سعر المنتج المسجل في قاعدة البيانات ومستوى VIP المعتمد للمستخدم.
2. **القيود الذرية في السجل المالي**: تتم جميع عمليات تعديل الرصيد ضمن معاملات متكاملة (`ACID Transactions`) مع قفل السجلات (`Row-level versioning`) لمنع التعديلات المتزامنة المتضاربة.
3. **سجل تدقيق المشرفين**: يتم تدوين كل قرار إداري يمس الأرصدة أو طلبات السحب في جدول `admin_audit_logs` متضمناً معرّف المشرف، عنوان IP، والتفاصيل المحاسبية.
4. **تمييز واضح لنمط المحاكاة التجريبي**: تظهر إشارات تحذيرية بارزة عند تفعيل النمط التجريبي لضمان عدم الخلط بين الأرصدة الافتراضية والأموال الحقيقية.
